# Code of Conduct

HydrogenOS follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, constructive, and specific. Harassment, discrimination, threats,
publication of private information, and sustained disruption are not accepted.
Project maintainers may remove content or participation that violates these
expectations. Conduct reports should be sent privately through the repository
owner's GitHub contact channel until a dedicated moderation address exists.
